# Friend-testing checklist

Ask friends to use the normal URL, not `?debug=1`.

For each tester, useful signals are:

- main persona feels right / partly right / wrong
- secondary persona feels right / wrong
- hardest question to answer
- question that felt repetitive
- sentence in the result that felt most accurate
- sentence that felt least accurate

For a suspicious result, ask the tester to repeat once using the debug URL and send the copied developer data.

Do not tune weights after one person's result. Look for repeated patterns across several testers first.
